# 📊 Customer Retention & Churn Analysis Dashboard

## 🔍 Project Overview

This project focuses on analyzing customer churn and retention patterns using customer subscription data. The dashboard was created in Microsoft Excel to identify key churn drivers, customer behavior trends, and business insights that can help improve customer retention.

The analysis simulates a real-world business scenario commonly used in SaaS and subscription-based companies.

---

# 🎯 Objectives

* Analyze customer churn patterns
* Identify high-risk customer segments
* Understand retention trends
* Analyze the impact of contract types and payment methods
* Provide actionable business recommendations

---

# 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning & Transformation

---

# 📂 Dataset Features

The dataset includes:

* Customer ID
* Gender
* Tenure
* Monthly Charges
* Total Charges
* Contract Type
* Payment Method
* Internet Service
* Churn Status

---

# 📊 Dashboard Features

## 🔹 Key Performance Indicators (KPIs)

* Total Customers
* Churned Customers
* Retained Customers
* Churn Rate
* Average Customer Tenure

---

## 🔹 Visualizations Included

* Overall Churn Rate (Pie Chart)
* Churn by Contract Type
* Churn by Payment Method
* Customer Tenure Trend
* Interactive Slicers

---

# 📈 Key Insights

* Customers with month-to-month contracts have the highest churn rate.
* Electronic check users show higher churn compared to other payment methods.
* Customers with long-term contracts are more likely to stay subscribed.
* Customers with longer tenure contribute more stable revenue.

---

# 💡 Recommendations

* Encourage customers to move to long-term contracts.
* Improve onboarding experience for new customers.
* Introduce loyalty rewards for high-risk customers.
* Improve customer experience for electronic payment users.

---

# 📌 Conclusion

This dashboard provides valuable insights into customer behavior and retention trends. The analysis helps businesses make data-driven decisions to reduce churn and improve long-term customer retention.
