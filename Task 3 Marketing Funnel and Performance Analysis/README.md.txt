Marketing Funnel & Conversion Performance Analysis

Project Overview

This project focuses on analyzing marketing funnel performance to identify customer conversion trends, drop-off stages, and opportunities to improve lead-to-customer conversion rates.

The analysis was completed as part of the Future Interns Data Science & Analytics Internship Task 3 (2026).


Objectives
Analyze customer conversion performance
Identify funnel drop-off points
Measure lead-to-customer conversion rates
Compare marketing channel performance
Provide business recommendations to improve conversions

Tools Used
Google Sheets
Pivot Tables
Charts & Dashboard Visualizations
Funnel Analysis Techniques

Dataset Used
Bank Marketing Dataset

The dataset contains marketing campaign information including:

Customer demographics
Contact methods
Campaign interactions
Conversion outcomes

Key Performance Indicators (KPIs)
Total Leads: 45,211
Total Customers Converted: 5,289
Total Drop-offs: 39,922
Conversion Rate: 11.7%

Dashboard Features
The dashboard includes:

Funnel overview chart
Monthly conversion trend analysis
Contact channel performance
Job category conversion analysis
KPI summary cards

Key Insights
A significant number of leads dropped before conversion.
Cellphone contact methods performed better than unknown contact methods.
Certain months recorded higher customer conversion activity.
Some customer job categories converted better than others.

Recommendations
Focus campaigns on high-converting customer groups.
Improve follow-up strategies to reduce drop-offs.
Optimize communication channels with better conversion rates.
Increase marketing efforts during high-performing periods.

Project Outcome
This project demonstrates the use of data analytics to support business decision-making and improve marketing conversion performance through actionable insights.
